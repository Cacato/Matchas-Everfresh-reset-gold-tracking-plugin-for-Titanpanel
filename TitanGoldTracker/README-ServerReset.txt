Matcha's Everfresh reset gold tracking plugin for Titanpanel

Requires Titan Panel 4.3.8.30300 / WoW 3.3.5. Close WoW and extract this ZIP
into Interface\AddOns, replacing TitanGoldTracker after backing it up.
Right-click built-in Gold Tracker to enable the server-reset gain section or
reset the account-wide baseline with confirmation. The baseline survives reload/logout.
Net gain subtracts spending; offline characters use their last recorded balance.
After a reset, log into each character before earning gold to set its baseline.
SavedVariables are preserved when replacing addon files.
Use /matchagolddebug for bounded balance diagnostics if needed.
Currency is a separate optional addon.
